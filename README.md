# Customer Churn Prediction App

A Machine Learning web application that predicts whether a telecom customer is likely to churn based on customer demographics, subscription details, and service usage patterns.

## Live Demo

🚀 Deployed Application:  
https://customer-churn-prediction-app-4a8h.onrender.com/

---

# Project Overview

Customer churn prediction is one of the most important business problems in the telecom industry. This project uses Machine Learning techniques to identify customers who are likely to leave the service.

The application allows users to:
- Input customer details
- Predict churn probability
- Analyze customer retention risk in real-time
